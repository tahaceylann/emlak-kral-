# Sunucu (M4 — henüz yok)

Gerçek zamanlı çok oyunculu için yetkili (authoritative) Node.js WebSocket
sunucusu bu klasöre gelecek: oda kur/katıl, tur/zar/ekonomi mantığının
sunucu tarafı kopyası, yeniden bağlanma desteği.

Şu an oyun tamamen istemci tarafında (`/client`), yerel botlarla oynanıyor.
Yol haritasının M4 aşamasında burası doldurulacak.
